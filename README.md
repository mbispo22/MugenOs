# MugenOs (無限)

**Um sistema infinito para a sua organização pessoal.**

Organize projetos, anotações e, em breve, as suas finanças e compromissos. Tudo num só lugar, com uma interface limpa e focada na produtividade.

### ✨ Funcionalidades

| Módulo | Status | Descrição |
| :--- | :--- | :--- |
| 📙 **Projetos** | ✅ **Funcional** | Crie e gira projetos com etapas, prazos e acompanhamento visual do progresso. |
| 📝 **Anotações** | ✅ **Funcional** | Um bloco de notas simples e rápido para capturar as suas ideias, com salvamento automático. |
| 💸 **Despesas** | 🚧 **Em Desenvolvimento** | Em breve, um módulo completo para controlo financeiro, com categorias e relatórios. |
| 📅 **Compromissos** | 🚧 **Em Desenvolvimento** | A sua futura agenda integrada, com calendário, lembretes e priorização de tarefas. |

### 🚀 Roadmap e Visão Futura

O nosso objetivo é criar um ecossistema de organização completo e integrado.

  - [x] Interface elegante com tema *dark*
  - [x] Sistema de Projetos com gestão de etapas
  - [x] Bloco de Notas com salvamento em `localStorage`
  - [x] Migração da base de código para **Vite + TypeScript**
  - [ ] Integração com **Supabase** para sincronização na nuvem
  - [ ] Sistema de autenticação de utilizadores
  - [ ] Módulo de Despesas
  - [ ] Módulo de Compromissos
  - [ ] Transformar em PWA para uma melhor experiência mobile

### 🛠️ Tecnologias Utilizadas

Este projeto foi construído com foco em tecnologias web modernas, sem depender de *frameworks* pesados.

| Área | Tecnologia |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, TypeScript, Web Components |
| **Ferramentas** | Vite (Servidor de Desenvolvimento e Build) |
| **Backend (Planeado)** | Supabase (PostgreSQL, Real-time, Auth, Storage) |
| **Deploy (Sugestão)**| Vercel / Netlify |

### ⚙️ Como Executar o Projeto Localmente

Para começar a desenvolver ou testar o MugenOs, siga estes passos:

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/mbispo22/MugenOs.git
    cd MugenOs
    ```

2.  **Instale as dependências:**
    (É necessário ter o [Node.js](https://nodejs.org/) instalado)

    ```bash
    npm install
    ```

3.  **Inicie o servidor de desenvolvimento:**

    ```bash
    npm run dev
    ```

4.  Abra o seu navegador e aceda a `http://localhost:5173` (ou o endereço que aparecer no seu terminal).
